# Priyanshu Srivastava Portfolio

A multi-page React + Vite portfolio for showcasing full-stack projects, AI/ML work, education, experience, and design/community leadership.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Structure

- `src/App.tsx` - lightweight hash routing between pages
- `src/data/portfolio.ts` - portfolio data, links, projects, skills, and timeline content
- `src/components/` - reusable layout, project, intro, and timeline components
- `src/pages/` - Home, About, Projects, and Contact pages
- `src/index.css` - global visual system, layout, and responsive styles
